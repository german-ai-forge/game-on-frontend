🎮 Game-On — Frontend
Streamlit frontend for the Game-On semantic video game search engine.
🔗 Backend Repository 
https://github.com/zxrey/Game-On-Project

⚙️ How It Works

User enters a query in natural language (English or Spanish)
The query is sent to the Game-On API via POST request
The API returns the top 5 recommended games with match scores and explanations
Results are displayed with real-time price, discount, trailer and Steam link
