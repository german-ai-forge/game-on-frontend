



# 🎮 Game-On — Frontend

Streamlit frontend for the Game-On semantic video game search engine.

🔗 [Backend Repository](https://github.com/zxrey/Game-On-Project)


## ⚙️ How It Works

1. User enters a query in natural language (English or Spanish)
2. The query is sent to the [Game-On API](https://github.com/zxrey/Game-On-Project) via POST request
3. The API returns the top 5 recommended games with match scores and explanations
4. Results are displayed with real-time price, discount, trailer and Steam link
